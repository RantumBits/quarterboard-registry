# The Quarterboard Registry

Static, searchable index of small American makers verified by
[The Quarterboard](https://quarterboard.co), a weekly newsletter on
American-made rugged prep. Every entry carries an origin label
(fully US-made / US-made line / disclosed nuance) and the date it was
last verified.

This repo holds the built page only. Data is exported from a private
verification database; corrections and maker suggestions:
hello@quarterboard.co.
